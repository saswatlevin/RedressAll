JWT (JSON Web Token) is an open standard (RFC 7519) for securely transmitting information between parties as a JSON object.
A JWT consists of 3 parts: header.payload.signature.

The header typically consists of two parts: the type of token (JWT) and the signing algorithm (HS256, RS256, etc.).
The payload contains the claims, which are statements about an entity (usually the user) and additional metadata.

* Why Refresh Tokens Are Necessary
  ** They allow us to issue short-lived access tokens while providing a mechanism to renew them without re-authentication.
  ** They enhance security by minimising the impact of compromised access tokens.
  ** They offer a better user experience by enabling seamless token renewal without disrupting user sessions.

* Passport Strategy vs. Guard in nestjs
  ** A strategy defines how you want to authenticate someone. Eg - Local Strategy for email/password login, JWT Strategy for verifying JWT tokens.
  ** A strategy checks credentials, validates the user data and returns the user data if valid.

* Guards are Gatekeepers for Routes
  ** A Guard is a NestJS concept that decides whether a request can go through to a route handler.

IN SUMMARY, THE STRATEGY DEFINES HOW TO AUTHENTICATE AND THE GUARD USES THE STRATEGY TO DECIDE IF ACCESS IS ALLOWED.
