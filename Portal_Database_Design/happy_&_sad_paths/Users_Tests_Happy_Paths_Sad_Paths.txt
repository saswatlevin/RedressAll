### createUser
01 -> Send an empty request body. [DTO] [SAD-PATH]
02 -> Create a user with all non-null attributes. [ENTITY - INTEGRITY]
03 -> Create a user with a duplicate user_mobile_no. [ENTITY - INTEGRITY]
03 -> Create a user with NULL user_first_name value. [DTO] [SAD-PATH]
04 -> Create a user with NULL user_last_name value. [DTO]
05 -> Create a user with NULL outlet_id [REFERENTIAL - INTEGRITY]

### updateuserName
01 -> Send an empty request body. [DTO] [SAD-PATH]
02 -> Update the user_first_name of an existing user to TEST_FIRST_NAME  
03 -> Update the user_first_name of an existing user to NULL [DTO] [SAD-PATH]
04 -> Update the user_last_name of an existing user from NULL to TEST_LAST_NAME [DTO]

### updateUserEmail
